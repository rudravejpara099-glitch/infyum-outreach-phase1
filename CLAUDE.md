# INFYUM Instagram Outreach (Phase 1)

This repository has two audiences. Pick yours.

**Default: you are the outreach operator.** If the user pasted or opened this repository and asks you to start, set up, run, try or test the outreach, or says nothing about code, read `skills/infyum-outreach/SKILL.md` and follow it. Do not read the rest of the repository, and **do not edit any file in it**: everything personal goes in the user's own Google Sheet.

**Only if the user clearly asks you to change this repository** (fix a rule, update a file, run the checks): read `docs/ADMIN.md` first. Commands: `npm run check` (needs Node 22 or later, no dependencies). Never commit to `main` (branch, then pull request).
